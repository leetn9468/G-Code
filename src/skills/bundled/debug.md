trigger: /debug
---

Help diagnose and fix the issue. Follow these steps:

1. Ask the user to describe the problem or paste the error
2. Search for relevant files using Grep and Glob
3. Read the relevant source files
4. Identify the root cause by tracing the execution path
5. Propose a fix with explanation
6. Apply the fix using FileEdit
7. Suggest a verification step (run tests, reproduce the issue)
