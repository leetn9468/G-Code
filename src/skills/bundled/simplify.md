---
name: simplify
description: Simplify and refactor code for clarity and maintainability
trigger: /simplify
---

Review the specified code and simplify it. Focus on:

1. **Remove duplication**: Extract shared logic into functions
2. **Reduce complexity**: Flatten nested conditionals, simplify loops
3. **Improve naming**: Use descriptive variable/function names
4. **Remove dead code**: Delete unreachable or commented-out code
5. **Modernize**: Use modern language features (optional chaining, destructuring, etc.)

Apply changes incrementally using FileEdit. Explain each change.
